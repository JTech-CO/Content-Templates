## 작성 조건

- 기본 분량: **공백 포함 250~450자**
- 사용자가 별도 분량을 입력한 경우: **[원하는 글자 수]자**
- 문단 구성: **2~4개 문단**, 문단 사이 한 줄 띄우기
- 문체: **담백한 존댓말 / `~어요`, `~했습니다` 어투**
- 형식: **네이버 쇼핑 상품 페이지에 바로 등록할 수 있는 댓글형 리뷰**
- 제목, 소제목, 번호, 목록, 링크, 해쉬태그는 출력하지 않습니다.
- 제품명과 브랜드명은 필요한 경우에만 1~2회 사용합니다.
- 장점만 나열하지 말고 구매 이유, 실사용 체감, 아쉬운 점, 추천 대상을 함께 반영합니다.
- 감탄사와 이모지를 반복하지 않으며 이모지는 전체에서 **0~1개**만 사용합니다.
- `내돈내산`, `직접 구매`는 사용자가 실제 구매로 입력한 경우에만 사용합니다.

## 카테고리별 반영 기준

### 식품·음료

- 맛, 향, 식감, 단맛이나 짠맛의 정도, 1회 분량, 보관과 조리 편의성을 중심으로 작성합니다.
- 건강 개선, 체중 감소, 질병 예방 효과를 단정하지 않습니다.

### 화장품·생활용품

- 향, 제형, 흡수감, 사용 편의성, 용기, 세척과 보관 등 실제 사용감을 중심으로 작성합니다.
- 피부 질환 치료, 미백·주름 개선 등 확인되지 않은 효능을 단정하지 않습니다.

### 가전·디지털

- 크기, 무게, 설치, 조작, 소음, 배터리, 연결성 등 사용자가 직접 확인한 항목만 반영합니다.
- 제조사가 제시하지 않았거나 사용자가 측정하지 않은 성능 수치를 만들지 않습니다.

### 패션·잡화

- 사용자가 입력한 신체 치수와 구매 사이즈를 기준으로 핏, 재질, 착용감, 마감 등을 작성합니다.
- 한 사람의 착용 결과를 모든 체형에 일반화하지 않습니다.

### 육아·반려동물

- 실제 사용 주체와 사용 상황을 분명히 하고, 안전성이나 건강 효과를 임의로 보장하지 않습니다.
- 연령, 체중, 사용 조건 등 입력된 정보가 있을 때만 구체적으로 언급합니다.

## 본문 구성

### 1문단. 구매 계기

- 어떤 필요나 고민 때문에 제품을 선택했는지 한두 문장으로 소개합니다.
- 직접 구매가 아니라면 구매했다고 표현하지 않고 제공 형태에 맞게 작성합니다.

### 2문단. 실사용 체감

- 사용 기간, 용량, 개수, 사이즈, 옵션 등 입력된 구체적인 정보 가운데 1개 이상을 자연스럽게 포함합니다.
- 제품의 장점을 나열하기보다 실제 사용 상황에서 어떻게 느껴졌는지 설명합니다.

### 3문단. 아쉬운 점과 사용 팁

- 아쉬운 점이 있다면 구매 전에 참고할 조건으로 담백하게 작성합니다.
- 사용자가 입력한 보완 방법이나 팁이 있으면 함께 제시합니다.
- 입력되지 않은 해결 방법을 임의로 만들지 않습니다.

### 4문단. 추천 대상과 재구매 의사

- 어떤 사람이나 상황에 적합한지 구체적으로 제시합니다.
- 전체 만족도와 재구매 의사를 과장 없이 마무리합니다.

## 대가성 표기

- 직접 구매한 경우에는 별도의 광고 문구를 만들지 않습니다.
- 제품 제공, 체험단, 원고료 등 대가가 있는 경우에는 사용자가 입력한 공개 문구를 지정된 위치에 원문 그대로 포함합니다.
- 플랫폼이 자동으로 체험단 여부를 표시하더라도 사용자가 별도 문구를 요구하면 누락하지 않습니다.

- 필수 공개 문구: [없음 / 지정 문구 입력]
- 공개 문구 위치: [본문 첫 줄 / 본문 마지막 줄]

## 주의할 표현

### 사용하면 좋은 표현

- “[용량 / 개수] 구성이라 [사용 상황]에서 쓰기 편했어요.”
- “[사용 기간] 동안 써보니 개인적으로 [구체적인 점]이 만족스러웠습니다.”
- “아쉬운 점은 [내용]이지만 [조건]을 확인하면 선택에 도움이 될 것 같아요.”
- “[추천 대상]에게는 잘 맞을 수 있지만 [조건]을 중요하게 보면 확인이 필요합니다.”

### 피해야 할 표현

- “무조건 사야 합니다.”
- “누구에게나 완벽합니다.”
- “효과가 바로 나타납니다.”
- “단점이 전혀 없습니다.”
- “다른 제품보다 무조건 최고입니다.”

제품의 효능, 안전성, 내구성, 배송 책임 등을 확인되지 않은 사실로 단정하지 않습니다.  
개인적인 체감은 “개인적으로”, “제가 사용했을 때”, “~한 느낌이었어요”처럼 범위를 한정합니다.
