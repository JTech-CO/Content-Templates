# 범용 댓글 리뷰 작성 템플릿

## 작성 요청

**[플랫폼명]**에 게시할 **[리뷰 대상]**의 짧은 댓글형 리뷰를 작성합니다.  
사용자가 실제로 방문하거나 사용하면서 기록한 내용을 1인칭 후기 문장으로 다듬으며, 입력되지 않은 경험·수치·기능·상황은 새로 만들지 않습니다.

## 작성 조건

- 전체 분량: **공백 포함 [원하는 글자 수]자**
- 기본 분량을 따로 입력하지 않았다면 **200~350자**로 작성합니다.
- 문단 구성: **1~3개 문단**, 문단 사이 한 줄 띄우기
- 문체: **자연스러운 존댓말 / `~어요`, `~했습니다` 어투**
- 형식: **플랫폼에 바로 등록할 수 있는 댓글형 리뷰**
- 제목, 소제목, 번호, 해쉬태그, 설명문은 출력하지 않습니다.
- 제품명이나 업체명을 반복하지 말고 필요한 경우에만 1~2회 사용합니다.
- 감탄사와 이모지는 최소화하며, 이모지는 전체에서 **0~2개**만 사용합니다.
- 장점만 나열하지 말고 실제 이용 상황, 구체적인 체감, 아쉬운 점 또는 추천 조건을 함께 반영합니다.
- 사용자가 제공하지 않은 가격, 방문 횟수, 사용 기간, 성능, 맛, 서비스 내용을 추측하지 않습니다.

## 실제 경험 메모

아래 정보 가운데 실제로 확인한 내용만 입력합니다.

- 이용 또는 사용 상황: [언제, 어디서, 어떤 목적으로 이용했는지]

## 본문 구성

### 1. 이용 또는 구매 계기

- 사용자의 상황이나 고민을 한두 문장으로 소개합니다.
- 과장된 후킹보다 실제로 선택하게 된 이유를 우선합니다.

### 2. 구체적인 경험

- 입력된 메뉴명, 옵션, 용량, 개수, 사용 기간, 대기 시간 등 확인 가능한 사실을 자연스럽게 포함합니다.
- “좋았다”, “괜찮았다”로 끝내지 말고 무엇이 어떻게 느껴졌는지 설명합니다.
- 객관적인 정보와 개인적인 체감을 구분합니다.

### 3. 아쉬운 점과 추천 조건

- 아쉬운 점이 입력된 경우 공격적이지 않은 표현으로 정리합니다.
- 해결 팁이 있다면 단점과 함께 제시합니다.
- 추천 대상과 재이용 의사를 담백하게 마무리합니다.

## 대가성 및 공개 조건

- 협찬, 제품 제공, 서비스 제공, 원고료, 제휴 수수료 등 대가가 있다면 아래 문구를 정확히 반영합니다.
- 플랫폼 또는 캠페인이 지정한 공개 문구가 있다면 사용자가 입력한 문구를 임의로 줄이거나 바꾸지 않습니다.
- 대가가 없는 경우에는 `내돈내산`, `직접 구매` 등의 표현을 사용자가 사실로 입력했을 때만 사용합니다.

- 대가성 여부: [없음 / 제품 제공 / 서비스 제공 / 원고료 / 제휴 수수료 / 기타]
- 필수 공개 문구: [없음 / 지정 문구 입력]
- 공개 문구 위치: [본문 첫 줄 / 본문 마지막 줄]

## 주의할 표현

### 사용하면 좋은 표현

- “직접 이용해보니 [구체적인 점]이 가장 먼저 느껴졌어요.”
- “개인적으로는 [상황]에서 이용하기 편했습니다.”
- “[조건]을 중요하게 보는 분이라면 참고할 만합니다.”
- “아쉬운 점은 [내용]이었지만 [팁]으로 보완할 수 있었어요.”

### 피해야 할 표현

- “누구에게나 무조건 좋습니다.”
- “단점이 전혀 없습니다.”
- “무조건 재구매해야 합니다.”
- “효과가 100% 있습니다.”
- “세상에서 가장 좋은 곳입니다.”

건강, 식품, 화장품, 의료기관 관련 리뷰에서는 치료·예방·개선 효과를 단정하지 않습니다.  
업체나 제품에 관한 위법성, 위생 문제, 사기, 고장 원인 등 확인되지 않은 사실도 추정해 작성하지 않습니다.

## 최종 작성 지시

위 정보를 바탕으로 **[플랫폼명]용 댓글 리뷰**를 작성합니다.

- 사용자가 제공한 실제 경험과 확인 가능한 정보만 반영합니다.
- 입력되지 않은 세부사항은 임의로 채우지 말고 자연스럽게 생략합니다.
- 지정된 분량과 문단 수를 지킵니다.
- 장점, 구체적인 체감, 아쉬운 점 또는 추천 조건이 균형 있게 드러나도록 작성합니다.
- 대가성 공개 문구가 있다면 지정된 위치에 원문 그대로 포함합니다.
- 최종 답변에는 리뷰 본문만 출력하고, 설명·머리말·제목·해쉬태그를 붙이지 않습니다.
