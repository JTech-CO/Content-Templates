# 네이밍 아이디어 콘테스트 제출용 프롬프트

회사/브랜드 한 줄 소개와 브리핑만 채운 뒤, 아래 **복사용 프롬프트**를 그대로 사용하면  
콘테스트 제출 형식에 맞는 시안 5개를 받을 수 있습니다.

---

## 사용 방법

1. `입력 정보`를 채운다.
2. `복사용 프롬프트` 전체를 복사한다.
3. `[한 줄 소개]`, `[브리핑]` 자리를 실제 내용으로 바꾼다.
4. 모델에 넣고 결과물을 제출문에 붙여 넣는다.

결과가 밋밋하면 `추가 지시`만 덧붙여 한 번 더 돌린다.

---

## 입력 정보

### 회사 또는 브랜드의 한 줄 소개

```
[예: 바쁜 직장인을 위한 10분 홈트레이닝 앱]
```

### 브리핑

아래 항목을 가능한 한 구체적으로 적는다. 비어 있는 항목은 `미정`으로 둔다.

```
- 사업/제품: 
- 핵심 가치·철학: 
- 타깃: 
- 경쟁 환경·차별점: 
- 원하는 인상(톤):     # 예: 신뢰 / 따뜻함 / 프리미엄 / 위트 / 테크 / 로컬
- 피하고 싶은 인상: 
- 필수 키워드: 
- 금지어·금기 연상: 
- 글자 수·음절 제한:   # 예: 국문 2~5자, 영문 8자 이내
- 언어 조건:           # 국문 우선 / 영문 우선 / 국영문 병기 필수
- 활용 범위:           # 사명, 제품명, 서비스명, 공간명, 캐릭터명 등
- 상표·도메인 고려:     # 예: 키프리스 통과 가능성 중시
- 참고 브랜드 / 하지 말 것:
- 기타 제약:
```

## 복사용 프롬프트

아래 블록을 통째로 복사한다.

````markdown
당신은 브랜드 네이밍 디렉터다.
아래 브랜드를 위한 **네이밍 아이디어 콘테스트 제출용 시안 5개**를 만든다.

역할:
- 심사위원이 한눈에 고를 수 있도록, 이름과 이유를 짧고 설득력 있게 쓴다.
- 이름은 부르기 쉽고, 의미가 분명하며, 브랜드 브리핑과 직접 연결되어야 한다.
- 흔한 직역, 진부한 합성어, 발음이 꼬이는 조어, 기존 유명 브랜드 모방은 하지 않는다.

# 입력

회사 또는 브랜드의 한 줄 소개:
[내용]

브리핑:
[내용]

# 작업 원칙

1. 시안은 정확히 5개. 서로 결이 달라야 한다.
   - 시안 1: 의미를 바로 읽히는 직관형
   - 시안 2: 브랜드 철학을 담은 상징형
   - 시안 3: 기억에 남는 조어/합성형
   - 시안 4: 감성·스토리형
   - 시안 5: 확장성 높은 플랫폼/세계관형
   (브리핑이 특정 방향을 강하게 원할 때는 그 방향을 우선하되, 5개가 한 패턴으로 몰리지 않게 한다.)

2. 각 시안은 국문/영문을 반드시 병기한다.
   - 국문명: 한국어로 자연스럽게 발음·표기되는 이름
   - 영문명: 해외 표기, 로고, 도메인, 앱스토어에 쓸 수 있는 이름
   - 국문과 영문이 같은 소리여도 되고, 의미가 대응되어도 된다. 억지 직역은 피한다.
   - 국문은 가능하면 2~6자, 영문은 가능하면 2~3음절. 브리핑에 글자 수 제한이 있으면 그것을 최우선한다.

3. 각 시안 설명은 한두 문장만 쓴다.
   - 1문장: 이름의 뜻/어원/말맛
   - 필요하면 2문장: 이 브랜드에 맞는 이유 또는 사용 장면
   - 미사여구, 수상 소감 톤, 장황한 마케팅 문장은 금지.

4. 반드시 통과해야 하는 품질 기준
   - 창의성: 이미 흔한 네이밍 클리셰가 아닐 것
   - 적합성: 한 줄 소개와 브리핑의 핵심을 담을 것
   - 발음성: 한국인이 한 번에 따라 말할 수 있을 것
   - 기억성: 듣고 바로 떠올릴 수 있을 것
   - 활용성: 로고, 슬로건, 앱, 패키지, 공간 사인에 올릴 수 있을 것
   - 식별성: 일반명사·품질 표시만으로 끝나지 않을 것
   - 리스크: 부정 은어, 동음이의 비하, 정치·종교 오해, 유명 상표 유사 연상은 피할 것

5. 하지 말 것
   - "~하다", "~하다" 식 동사 나열 이름
   - 알파벳+한글 난잡 혼합 (브리핑이 요구할 때만 허용)
   - 숫자 남용, 과도한 하이픈, 발음 불가능한 자음 충돌
   - "스마트/케어/라이프/파트너/솔루션/플랫폼/네이처/그린"만 붙인 이름
   - 설명문을 이름처럼 쓰는 것

# 출력 형식

아래 형식을 한 글자도 바꾸지 말고 그대로 따른다.
머리말, 총평, 해시태그, 추천 순위 설명은 쓰지 않는다.
시안 본문만 출력한다.

# 네이밍 아이디어 콘테스트 제출용

회사 또는 브랜드의 한 줄 소개:
{입력된 한 줄 소개를 그대로}

브리핑:
{입력된 브리핑을 핵심만 3~6줄로 재정리. 새로운 사실을 지어내지 말 것}

## 시안 01. {국문명} / {영문명}
{한두 문장 설명}

## 시안 02. {국문명} / {영문명}
{한두 문장 설명}

## 시안 03. {국문명} / {영문명}
{한두 문장 설명}

## 시안 04. {국문명} / {영문명}
{한두 문장 설명}

## 시안 05. {국문명} / {영문명}
{한두 문장 설명}
````

## 추가 지시 (필요할 때만 붙여 넣기)

결과가 약할 때 프롬프트 맨 아래에 한 줄만 추가한다.

```
이번 결과는 탈락이다. 더 날카롭게 다시 뽑아라.
- 5개 모두 서로 다른 조어 전략을 쓸 것
- 각 국문명은 실제로 로고에 올렸을 때 예쁠 것
- 설명 첫 문장에 어원 또는 말맛을 분명하게 밝힐 것
- 기존 유명 브랜드와 3음 이상 비슷한 이름은 버릴 것
```

특정 톤이 필요하면 아래 중 해당하는 것만 붙인다.

```
톤 고정: 차갑고 짧은 프리미엄. 귀엽거나 장난스러운 조어 금지.
톤 고정: 말맛 있는 한글. 한자어 남용 금지.
톤 고정: 글로벌 론칭용. 영문이 주 이름, 국문은 음차 또는 짧은 애칭.
제약 추가: 상표 식별력을 위해 일반명사 단독 사용 금지.
제약 추가: 발음이 /ㄹ/ /ㄴ/ 연속으로 꼬이는 이름 금지.
```

제출 전에 한 단계 더 다듬고 싶으면:

```
방금 뽑은 5개 시안을 콘테스트 제출문으로 다듬어라.
- 이름과 영문 표기는 유지
- 설명만 더 짧고 심사위원용으로 다시 써라
- 각 설명은 공백 포함 80자 이내
```

## 제출 전 체크

- [ ] 시안이 정확히 5개인가
- [ ] 모든 시안에 국문 / 영문이 있는가
- [ ] 설명이 한두 문장인가
- [ ] 5개가 비슷한 말맛으로 뭉치지 않았는가
- [ ] 브리핑의 핵심 단어가 설명에 실제로 연결되는가
- [ ] 큰 소리로 읽었을 때 걸리는 발음이 없는가
- [ ] 부정 은어·동음이의·기존 브랜드 유사 연상이 없는가
- [ ] 공모요강 글자 수 제한을 지켰는가

실제 출품 전에는 키프리스(상표)와 기본 도메인 검색을 따로 하는 것을 권한다.  
이 프롬프트는 아이디어 시안용이며, 등록 가능성을 보장하지 않는다.

## 미니 예시 (입력 → 출력 모양)

입력 예시:

```
회사 또는 브랜드의 한 줄 소개:
비 오는 날에도 신는 가벼운 도시 레인부츠

브리핑:
- 제품: 출퇴근용 경량 레인부츠
- 타깃: 2030 도시 직장인
- 톤: 담백, 세련, 과장 없는 실용
- 금지어: 키즈·귀여움·캐릭터 연상
```

출력 모양 예시:

```
# 네이밍 아이디어 콘테스트 제출용

회사 또는 브랜드의 한 줄 소개:
비 오는 날에도 신는 가벼운 도시 레인부츠

브리핑:
출퇴근용 경량 레인부츠. 2030 도시 직장인 대상.
담백하고 세련된 실용. 키즈·캐릭터 연상은 배제.

## 시안 01. 구름길 / Cloudpath
비 온 뒤의 길을 가볍게 잇는다는 뜻이다. 출퇴근길의 불편을 덜어 주는 부츠라는 쓰임이 바로 읽힌다.

## 시안 02. 온각 / ONGAK
‘온전한 각’과 ‘온 거리’를 겹친 이름이다. 젖은 路面에서도 발의 감각이 살아 있다는 제품 경험을 짧게 담는다.
```

위는 형식 예시일 뿐, 실제 브랜드에는 사용하지 않는다.
